# Коробка TV (Box-TV)

Нативное Android приложение для комфортного просмотра фильмов и сериалов на **Android TV, проекторах, планшетах и смартфонах**. 

Разработано на **Kotlin**, **Jetpack Compose** и **Media3 ExoPlayer** без использования WebView и лишних оберток.

## ✨ Ключевые возможности

### 🎨 Кинематографичный интерфейс
- **Премиальный Hero-баннер**:
  - Атмосферный фон с сильным размытием обложки (`blur(32.dp)`).
  - Мягкий полупрозрачный градиент для кристальной читаемости текста.
  - Высокий четкий постер **2:3** в правой части карточки.
- **Единый стиль карточек**:
  - Карточки в разделах «Продолжить просмотр», «Избранное» и «Поиск» выполнены в едином вертикальном киноформате **2:3**.
  - На постерах истории отображается красная линия прогресса досмотренности.
  - Названия строго зафиксированы в 2 строки без скачков и сдвигов соседних элементов.

### 📱 Полная адаптивность (TV, Проекторы, Телефоны, Планшеты)
- **Android TV и проекторы**:
  - Управление стандартным пультом D-Pad.
  - Тонкая аккуратная обводка активного элемента (1.5dp) с инверсией цвета для четкой видимости на любых проекторах без скачков масштаба.
- **Смартфоны и планшеты**:
  - Поддержка вертикальной ориентации (Portrait) и автоповорота.
  - Результаты поиска отображаются в адаптивной двухколоночной сетке.
  - Поддержка нативной системной клавиатуры (Gboard, Samsung Keyboard и др.) с клавишей поиска.
  - Свайп снизу вверх в плеере для быстрого вызова настроек серий и озвучки.

### 🎬 Плеер ExoPlayer (Media3)
- Мгновенное бесшовное переключение аудиодорожек и студий озвучки (LostFilm, Кубик в Кубе, Дубляж и др.) без сброса позиции.
- Выбор качества потока (1080p FHD, 720p HD, 480p SD).
- **Плавающая подсказка при паузе**: при остановке видео снизу мягко появляется ненавязчивое затенение с крупной подсказкой перехода в меню (открывается кликом, свайпом вверх или стрелкой вниз на пульте).
- **Умное меню серий**: перелистывание сезонов не прерывает просмотр текущей серии до явного выбора.
- **Автопереход к следующей серии**: диалоговое окно в конце серии с возможностью мгновенного запуска следующего эпизода или следующего сезона.
- Автоматическое сохранение таймкода и озвучки в историю каждые несколько секунд.

## 🛠 Сборка из исходников

### Требования
- JDK 17+
- Android SDK (API 34–36, Build-Tools 36+)

### Сборка релизного APK
```bash
./gradlew assembleRelease
```

### Подпись и установка через ADB
```bash
# 1. Подпись сгенерированного APK
apksigner sign --ks ~/.android/debug.keystore \
  --ks-pass pass:android \
  --key-pass pass:android \
  app/build/outputs/apk/release/app-release-unsigned.apk

# 2. Установка на Android TV или смартфон
adb connect <IP_АДРЕС>:5555
adb install -r app/build/outputs/apk/release/app-release-unsigned.apk
```

## 🏗 Архитектура проекта

```
app/src/main/java/com/korobka/tv/
├── MainActivity.kt               # Точка входа в приложение (TV Leanback & Mobile)
├── ui/
│   └── MainTvScreen.kt           # Главный экран Compose (Hero, постеры 2:3, поиск, клавиатура)
├── player/
│   └── NativePlayerActivity.kt   # ExoPlayer, D-Pad и тач-управление, оверлеи, озвучки, сезоны
├── engine/
│   └── CdnEngine.kt              # Сетевой клиент HLS потоков, парсер манифестов и метаданных
└── data/
    ├── Models.kt                 # Модели (MediaItem, Episode, Season, StreamSource)
    └── AppStorage.kt             # Локальное хранилище истории просмотров и избранного
```
